# Gerador SPED Fiscal Contalger — Perfil A 3.6

Versão preparada para publicação no GitHub Pages.

## Publicação rápida

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

O arquivo principal já está nomeado como `index.html`.

## Arquivos

- `index.html` — aplicativo completo.
- `.nojekyll` — evita processamento desnecessário pelo Jekyll no GitHub Pages.
- `README.md` — instruções de publicação.

## Observação

O aplicativo roda no navegador. Os dados e configurações salvos localmente usam o armazenamento do próprio navegador.
